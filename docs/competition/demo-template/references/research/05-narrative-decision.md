# 主叙事与主 Demo 裁决记录

## 日期

2026-10-18

## 用户裁决

选择 **C：管家前台 + 平台后台**，主 Demo 选择 **可疑扣款处置**。

## 主叙事

- 对外：银序是一个懂你的个人财务管家，从账单到转账、理财、卡片，一句话把事办完。
- 对评委：银序是一个让银行 Agent 办得成、拦得住、查得清的可信执行平台。
- 封面和开场用前者，架构和安全页用后者。

## 选择理由

1. 管家叙事让用户价值和场景更容易理解。
2. 平台叙事支撑安全合规 30% 和技术可信度。
3. 可疑扣款同时覆盖任务完成、安全拦截、跨场景联动和审计回放。
4. 相比发薪日，可疑扣款的安全戏剧性更强；相比订阅清理，业务后果更高。

## 未选择的方向

- 纯平台叙事：容易显得冷、技术味重，用户价值不直观。
- 纯管家叙事：容易被评委当成聊天机器人，安全深度不足。
- 发薪日作为主 Demo：商业价值强，但安全冲突不够集中。
- 订阅清理作为主 Demo：用户价值直观，但高风险动作和人工接管展示不足。
