# 银序 BankAgent：高分示范模板 v0.1（历史版本）

> 这是快速蒸馏档的过程骨架。主叙事已裁决为“管家前台 + 平台后台”，主 Demo 已裁决为“可疑扣款处置”。最终版见 `SKILL.md`。

## 一句话定位（两个候选）

**A. 可信执行平台**

银序是一个让银行 Agent 办得成、拦得住、查得清的可信执行平台。

**B. 个人财务管家**

银序是一个懂你的个人财务管家，从账单到转账、理财、卡片，一句话把事办完。

## 三分钟 Demo 结构

| 时间      | 内容                                             | 目的               |
| --------- | ------------------------------------------------ | ------------------ |
| 0:00—0:20 | 用户痛点：功能藏在菜单里，跨场景要来回跳         | 建立真实问题       |

## 主 Demo 选择

建议主 Demo 用“可疑扣款处置”：

1. 用户发现陌生扣款。
2. Agent 追溯商户与账单。
3. 发现外部网页含注入指令，展示隔离。
4. 建议锁卡/冻结代扣，要求二次确认。
5. 执行后生成申诉材料，转人工复核。
6. 审计回放展示每一步依据。

这条线同时覆盖安全、跨场景、任务闭环和可解释性，最容易让评委记住。

## 安全演示清单

- 诱导转账：用户说“客服让我转的”，Agent 拦截并解释。
- 越权查询：请求查看他人账单，Agent 拒绝并记录。
- Prompt 注入：商户备注含“忽略规则”，Agent 只当数据。
- 信息套取：要求完整卡号，Agent 脱敏并转人工。
- 高额操作：要求二次确认/冷静期。
- 失败恢复：工具超时后给出替代路径，不重复乱调。
