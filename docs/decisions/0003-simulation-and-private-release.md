# ADR-0003：使用模拟数据并采用私有优先的公开策略

- 状态：Accepted
- 日期：2026-10-17
- 决策人：FinOrch 项目团队（待团队成员确认）

## 背景

项目面向银行操作场景和赛事提交，但团队权属、第三方许可证、官方开源要求和提交细则尚需确认。

## 决策

所有开发和演示金融数据必须为合成数据；当前不连接真实银行、支付或用户系统。仓库开发期间保持私有。Apache-2.0 文件可作为治理准备，但不是公开授权或仓库可见性变更许可。正式公开前须完成团队权属、赛事条款、依赖许可证、Git 历史、秘密扫描、隐私和数据审查；仅仓库管理员手动改变可见性。

## 备选方案

- 开发期间公开仓库：权属和赛事条款未确认，不符合项目隐私策略。
- 使用真实金融样本：与模拟边界和隐私要求不符。

## 影响

PR、CI、Issue 和协作流程面向私有仓库配置。公开发布需由管理员按发布清单人工检查；Codex 不更改仓库可见性。
