# BankMate 安全自评报告

## 评估范围

本报告覆盖服务端身份与资源归属、Agent 工具调用、风险分级、操作确认、强验证、幂等、事务、审计、异常熔断与任务接管。评估基于当前代码和对应自动化回归测试。

## 自评结论

系统对只读请求执行资源归属校验；业务写操作由服务端确认流程控制；部分高风险操作增加一次性验证码验证。金额和业务结果由服务端计算，确认消费、业务状态和审计记录在事务中处理。

账户、交易、产品和操作使用虚拟数据，不连接真实银行、支付网络或商户。

## 权限分级

| 等级 | 操作方式               | 已实现范围                                                             |
| ---- | ---------------------- | ---------------------------------------------------------------------- |
| 绿色 | 资源归属校验后查询     | 账户、流水、银行卡、账单及其他已实现查询                               |
| 黄色 | 展示影响并等待用户确认 | 普通转账、订阅变更、卡片管理和一般模拟理财操作                         |
| 红色 | 用户确认并完成额外验证 | 高额转账、较高风险等级产品申购、挂失补卡、指定额度调整和高金额模拟订单 |

红色操作由服务端 `risk-v1` 策略判定。当前一次性验证码通过本地命令生成，并绑定对应确认挑战。

安全相关回归测试共 **106 项通过**，覆盖身份和资源归属、风险策略、确认挑战、强验证、幂等与事务、银行卡限额、异常熔断和人工接管。

## 已实现的安全控制

1. **服务端授权：** 客户端不能通过提交用户 ID 或角色获得权限；读写操作均检查资源归属。
2. **受控工具：** Agent 仅调用已注册工具，所有参数经过 Schema 和业务规则校验。
3. **操作确认：** 确认内容绑定用户、工具、参数、资源版本、有效期和幂等键，执行前重新校验。
4. **强验证：** 高风险操作按服务端策略追加一次性验证码校验。
5. **资金一致性：** 金额使用整数最小货币单位；业务状态、确认消费和审计记录通过事务保持一致。
6. **审计脱敏：** 记录操作对象、结果和时间，不记录密钥、验证码或完整 Prompt。
7. **安全失败：** 未知工具、无效参数、权限不足、余额不足、版本冲突及模型错误不会被报告为成功。
8. **网络与数据外发：** API 仅绑定本机回环地址，接口响应禁止缓存；外部模型请求默认关闭，启用前需显式授权，远端仅使用 HTTPS，且不跟随重定向。页面显示当前外发开关状态。
