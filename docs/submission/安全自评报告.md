# BankMate 安全自评报告

评估日期：2026 年 10 月 27 日

## 评估范围

本次自评覆盖本地合成数据环境中的身份范围、工具调用限制、风险策略、确认挑战、强验证、幂等、事务、审计、异常熔断与任务接管。评估对象为当前仓库实现及其自动化回归测试。

系统不连接真实银行、支付网络或商户。本报告是项目组的代码自查和自动化测试记录，不是第三方渗透测试、合规认证或独立人工安全审查。

## 自评结论

当前版本在本地虚拟业务环境中形成了服务端控制的读写边界：查询按资源归属校验；普通写操作需用户确认；适用的高风险操作增加本地一次性验证；金额和业务结果由服务端计算；确认消费、业务状态与审计在事务内提交。

**结论：可用于合成数据下的竞赛演示与开发验证；不应接入真实账户或用于真实资金操作。**

## 权限策略自评

| 等级 | 策略                         | 当前实现范围                                                                                  |
| ---- | ---------------------------- | --------------------------------------------------------------------------------------------- |
| 绿色 | 资源归属校验后执行只读查询   | 账户、流水、银行卡、账单及其他已实现查询                                                      |
| 黄色 | 展示影响并等待用户确认       | 普通转账、订阅变更、卡片管理及一般模拟理财写入                                                |
| 红色 | 用户确认，并按策略增加强验证 | 高额转账、R4/R5 产品申购、挂失补卡、指定额度调整和高金额模拟订单等；由 risk-v1 服务端策略判定 |

当前强验证使用本地命令行生成的一次性验证码，并绑定确认挑战；它不是银行短信、活体或生产级 MFA。页面展示具体确认内容，但尚无独立红黄绿灯组件。

## 已落实的主要控制

1. **服务端身份和授权：** 客户端传入的用户 ID 或角色不能自行授予权限；查询与写入均按 actor 校验资源归属。
2. **受控工具：** Agent 仅能调用注册工具，参数需通过 Schema 校验；不执行模型生成代码或任意 Python。
3. **确认和防重放：** 挑战绑定 actor、工具、参数摘要、资源版本、策略版本、有效期和幂等键；服务端在执行前重新校验。
4. **资金与数据一致性：** 金额用整数最小货币单位保存；状态变化、确认消费和审计在事务中提交；失败时回滚。
5. **审计与脱敏：** 审计记录操作类别、对象、结果和时间；不保存密钥、验证码或完整 Prompt。
6. **异常处理：** 模型超时、未知工具、Schema 错误、余额不足、权限不符和版本冲突不会被包装为成功。
7. **合成数据：** 当前演示账户、流水、产品、订单和交易结果均为虚拟数据。

## 未解决风险

| 优先级 | 风险                             | 当前影响                                     | 后续措施                                                           |
| ------ | -------------------------------- | -------------------------------------------- | ------------------------------------------------------------------ |
| 高     | 没有生产级用户认证和会话管理     | 模拟身份不能保护真实用户账户                 | 若接入真实服务，先设计并独立验证身份、会话和授权                   |
| 高     | 本地一次性验证码不是强身份认证   | 无法证明操作由真实账户持有人在可信设备上批准 | 真实业务需接入受审查的认证与风险策略；不得复用当前验证码机制       |
| 高     | 模型服务可能接收用户输入和上下文 | 真实个人或账户资料可能离开本地环境           | 演示只输入虚拟信息；启用外部 Provider 前审查数据处理条款与传输范围 |
| 中     | 异常提示基于规则                 | 可能误报或漏报，不能确认欺诈                 | 仅作为核对提示；不能据此自动冻结真实账户                           |
| 中     | SQLite、单进程调度和本地熔断     | 未覆盖多实例竞争、灾难恢复和生产负载         | 真实部署前需单独评估存储、并发、备份和监控                         |
| 中     | 审计和任务上下文保存在本地数据库 | 含用户输入的任务内容需要按敏感信息管理       | 限制本地文件访问；公开前检查历史、日志、样例和数据库文件           |
