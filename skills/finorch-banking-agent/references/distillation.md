# 蒸馏依据与边界

## 来源

### 微众银行公开实践

来源：2026 FinTechathon 技术公开课截图与赛事公开材料。

可迁移模式：

- AI 嵌入核心业务流程，不是独立聊天入口。
- 离线 + 实时双模式共用模型能力。
- 人机协作：一人监督多路 Agent，触发条件介入，结果回写。
- 策略大脑与质检/分析闭环。
- 证据定位、审计、申诉复核。
- AI 工程化平台：统一接入、权限、审计、安全、监控、Agent/MCP/知识库/模型中心。

不要照搬：内部质检/外呼/跨境流程、宣传数字、缺少失败率的结论。

### Sierra AI

来源：Sierra 官方产品页。

可迁移模式：

- Guardrails 在构建时存在，不是事后补丁。
- 全链路可观测：工具调用、知识查询、延迟、推理面板。
- 人工转接原因可分析。
- 长程规划、客户上下文、在边界内优化结果。
- 主动服务由现实信号触发 next-best-action。

不要照搬：企业客服商业模式、营销材料、未公开的安全方法。

### Rocket Money

来源：Rocket Money 官方首页与功能页。

可迁移模式：

- 订阅识别、跟踪、取消。
- 账单提醒、消费洞察、账单谈判。
- 节省金额量化。
- AI 助手承接“帮我省钱”的目标。

作为主消费金融体验参考。Copilot Money 只作为预算/投资/净资产总览的视觉参考。

不要照搬：美国订阅/商户生态、取消接口假设、非银行 Agent 的完整能力。

### Anthropic Agent 方法

来源：Anthropic, Building Effective AI Agents。

可迁移模式：

- workflow 与 agent 的区分。
- 先找最简单方案，只在需要时增加自治。
- 可组合模式、工具边界、evaluator-optimizer、human-in-the-loop。

不要照搬：把通用 agent 框架当成产品架构。

### DeepSeek Search/Fetch

来源：DeepSeek 官方 Search/Fetch 指南。

可迁移原则：外部网页是只读、不可信输入，必须来源校验、隔离和引用，不能直接触发高风险动作。

## 五个核心原则

1. 受控工作流，而不是无限自治。
2. 信任是可见的产品表面。
3. 闭环结果，而不是对话完成。
4. 主动但有边界。
5. 外部内容不可信。

每个原则都同时对应评分：

- 任务完成：真实工具调用、状态变化、失败恢复。
- 安全合规：权限、确认、注入隔离、人工接管、审计。
- 创新交互：目标导向、事件驱动、跨场景、可解释回放。

## 当前裁决

- 主叙事：管家前台 + 平台后台。
- 主 Demo：可疑扣款处置。
- 消费金融体验：Rocket Money 主，Copilot Money 只做视觉。
- 六个场景：全部作为一级模块，三条主线串联。

这些是当前假设，可以随用户裁决修改。

仓库当前进展：Phase 1A 银行底座和 Phase 1B 卡片冻结/解冻切片已实现；其余场景仍为 Planned。设计模板不能替代实现状态。

## 快速档边界

- 只使用公开资料和公开课材料，没有用户访谈。
- 没有获取往届获奖队伍的完整答辩材料。
- 产品页偏营销，缺少独立失败率。
- 不能把参考对象的能力当成 FinOrch 已实现能力。
- 任何安全/业务结论都要由本项目自己的测试和评审支撑。
